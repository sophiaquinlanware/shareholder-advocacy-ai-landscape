# docs/design

Mockups, reference images and before/after screenshots for visual changes, named `YYYY-MM-DD-topic-before-<size>-<theme>.png` and `...-after-...`.

`npm test` writes a full-page screenshot of every tab at every size and theme to `tests/screenshots/<size>-<theme>/<tab>.png` (git-ignored). Copy the ones a change affects here: once before starting, and once after.

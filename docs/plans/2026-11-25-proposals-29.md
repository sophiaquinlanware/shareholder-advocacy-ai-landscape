## What changes

1. **`data/proposals.json`** gains AI-related shareholder proposals (2023 meetings onward) at the 22 companies added to the rights map: Anthropic, SpaceX, IBM, Salesforce, Adobe, Intuit, Verisk, Workday, ServiceNow, Palantir, Cisco, Axon, Motorola Solutions, Netflix, Disney, Comcast, Oracle, AMD, Broadcom, CoreWeave, Digital Realty, Southern. Same fields and topic tags as the existing records; support = For / (For + Against) from the 8-K Item 5.07, with the company's own basis noted where different.
2. **Filing deadlines.** On each company in `data/companies.json` (all 29): `next_proposal_deadline` (ISO date) and `next_proposal_deadline_source` (the latest DEF 14A, where it states when Rule 14a-8 proposals for the next meeting must be received). On each proposal where available: `filing_deadline` and `filing_deadline_source` (the prior year's proxy sentence).
3. **`vote_history`** on proposals: earlier votes at the same company on the same subject, each with year, support and results URL. Set only where the proxy, the filer or the titles make it the same subject; each link sourced to its vote results.
4. **`seeking`** stays empty unless a public call for co-filers is found.
5. `build_graph.py` passes the new fields to graph nodes; `build_value_chain.py` then counts proposals for every tier.

## Method

Researchers read sec.gov filings (WebFetch, or the built-in browser where WebFetch is rate-limited). The same AI test as before: AI governance, safety, data center impacts, social and economic impacts. Floor proposals keep null support.

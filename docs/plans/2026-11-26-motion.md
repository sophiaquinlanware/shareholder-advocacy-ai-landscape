# Plan: UI and motion layer (staged)

Date: 2026-11-26. UI session. The owner pasted a brief: "Upgrade the UI and motion layer of the tracker. Don't change the data, structure, or features, only how it looks and feels … calm, credible, editorial. Restraint over flash. Every motion should help the reader understand the data. … Apply the foundation first and show me, then layer in motion one element at a time so I can review each."

## Owner decisions where the brief met earlier choices (asked 2026-11-26)

- **Background:** "Keep plain white". The brief's #F7F6F3 is not used.
- **Headings:** "Keep the grotesque". No serif; Schibsted Grotesk throughout.
- **Nav on scroll:** "Title always visible". The tab rows tuck away on scroll down and return on scroll up; the page title stays.
- **Accent:** the one blue #1f4e98 (chosen earlier the same day) is the brief's "ink blue".

## Stages (each one built, checked, published and shown before the next)

1. **Foundation (this stage).**
   - Lenis smooth scroll synced with GSAP ScrollTrigger (`lenis.on('scroll', ScrollTrigger.update)`, `lenis.raf` on `gsap.ticker`, `lagSmoothing(0)`). It is off under reduced motion. The graph boxes carry `data-lenis-prevent`, so wheel zoom still works there.
   - Tokens:
     - one easing, `--ease: cubic-bezier(0.16, 1, 0.3, 1)`;
     - durations `--dur-micro` 200ms, `--dur-reveal` 500ms, `--dur-trans` 800ms;
     - an 8px spacing scale, `--s-1`…`--s-8`.
   - Every existing transition moves to the one easing.
   - Text is near-black #1a1a1a. Tabular numerals apply everywhere.
   - Space is reserved for each panel, and the fallback font is already metric-matched.
   - The sticky bar's tuck animates opacity only. The height change is instant, and the browser keeps the content still. This follows "animate only transform and opacity".
2. Headline line-by-line mask reveal on load.
3. Stat numbers count up once in view.
4. Charts draw in on scroll, with hover tooltips. Vote support bars fill, with a 50% marker.
5. Table rows fade in with a stagger; filter changes animate rows in and out.
6. Status timelines step through.
7. View Transitions crossfade between tabs, and skeletons instead of "Loading".
8. Micro-interactions:
   - link underlines draw in;
   - cards lift 3px;
   - buttons press to 0.98;
   - row hover;
   - soft status pills;
   - a scroll-progress bar;
   - filter chips animate.
9. Cmd+K quick search overlay.
10. Mobile: simpler motion, and remaining tables as stacked cards.

## Non-negotiables (every stage)

- Under reduced motion, only simple fades.
- Only transform and opacity are animated.
- Visible focus, with contrast kept.
- No heavy 3D, no scroll-jacking (Lenis smooths native scroll and never takes control of it), and no loading screens.
- Libraries come pinned from cdnjs or jsdelivr and load without blocking. Nothing here changes data, structure or features.

## Files (stage 1)

- `motion.js` (new): Lenis and GSAP set-up, plus `window.MOTION` for later stages.
- `index.html`: scripts.
- `styles.css`: tokens, easing, numerals, Lenis CSS.
- `DESIGN.md` and `docs/STATE.md`.
